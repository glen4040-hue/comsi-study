# 컴시응 Study Mobile V1.3

모바일 우선 개인 학습 PWA입니다.

## V1.3 추가 기능
- 문제별 학습상태: 미학습 / 학습중 / 복습필요 / 완료
- 홈 학습진도 및 복습필요 바로가기
- 문제별 핵심 키워드 저장
- 기존 모범답안 / 내 답안 / 메모 / 즐겨찾기 유지
- 기출 목록 학습상태 필터 및 상태 배지
- 1교시형 랜덤 13문제 모의고사
- 100분 타이머 및 작성 진행률
- 모바일 가로 overflow 방지 유지

기존 V1.2의 localStorage 데이터는 동일 키를 사용하므로 그대로 유지됩니다.
