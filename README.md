# 컴시응 Study Mobile v1.5.4

## 객관식 정답 위치 오류 수정
- 120문항 정답이 모두 1번이던 오류 수정
- 정답 위치를 1~4번에 정확히 30문항씩 균등 배치
- 정답 이동 시 오답 선택지 순서도 함께 재배열
- 동일 정답 번호의 과도한 연속 패턴 방지
- 문제, 해설, 기출 연계 정보는 그대로 유지

## 정답 위치 분포
- 1번: 30문항
- 2번: 30문항
- 3번: 30문항
- 4번: 30문항

## 기존 기능 유지
- 객관식 120문항 및 오답노트/정답률 통계
- 1~4교시 실전 모의고사
- 서술형 연습모드
- 제134·135회 학습용 기본답안
- 다크/라이트 모드
