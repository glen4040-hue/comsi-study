# 컴시응 Study Mobile v1.5.0

## 주요 변경
- 제135회 전체 31문항에 AI 작성 학습용 예시답안 기본 탑재
- 공식 모범답안과 혼동하지 않도록 안내문 표시
- 기본답안(read-only) / 내 수정본 / 내 답안 3단 구조로 개편
- [내 수정본으로 복사] 버튼 추가
- 기존 V1.x에서 사용자가 작성한 modelAnswer는 내 수정본으로 호환
- 연습모드·모의고사 자기채점 시 내 수정본 우선, 없으면 기본답안을 자동 사용
- 제135회 일부 기본 분류 정제 및 기본 키워드 추가
- 답안 데이터를 answers-135.js로 분리하여 향후 회차별 Git 관리 용이

## 주의
탑재된 답안은 국가기술자격 공식 채점기준/공식 모범답안이 아니라 학습용 예시답안입니다.
