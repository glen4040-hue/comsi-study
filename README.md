# 컴시응 Study Mobile V1.2

모바일(PWA) 전용 개선 버전입니다.

## 주요 변경
- Kakao 인앱브라우저/iPhone에서 긴 문제 문자열로 인한 가로 잘림 방지
- 모든 주요 컨테이너에 overflow 방지 및 긴 영문 강제 줄바꿈 적용
- 기출 카드 UI 재설계: 회차/교시/번호 배지, 분야 태그, 카드 내 즐겨찾기
- 검색 및 가로 스크롤 필터
- 최신순/오래된순 정렬
- 즐겨찾기만 보기
- 통계에 건수 + 비율 표시
- 다크모드를 모바일 기본값으로 설정
- Service Worker 캐시 버전 갱신(comsi-v12)
