## 답안 작성 원칙
- 공식 모범답안이 아닌 기술사 학습용 예시답안
- 1교시: 정의 → 핵심기술/특징 → 활용·고려사항 중심
- 2~4교시: 개요 → 구조/원리 → 비교/대응 → Best Practice 중심
- 표준/정책 문제는 출제주제의 핵심 구조와 실무 포인트 중심으로 정리
