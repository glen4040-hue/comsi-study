# 컴시응 Study Mobile v1.5.1

## 변경사항
- 객관식 문제은행 10문항 → 120문항 확대
- 공식 출제기준 8대 분야별 15문항씩 구성
- 기출 토픽 기반 학습용 객관식으로 재구성
- 객관식 분야 선택 기능 추가
- 10 / 20 / 30 / 50 / 전체 문제 수 선택 기능 추가
- 매 시험마다 선택 범위에서 랜덤 출제
- 해설과 연계 기출 회차·교시 표시
- 기존 v1.5.0 학습용 기본답안 및 모의고사 기능 유지

※ 객관식 문항과 해설은 공식 기출의 객관식 정답이 아니라,
기출 토픽을 기반으로 만든 학습용 문제입니다.
