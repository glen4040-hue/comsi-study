## 답안 작성 원칙
- 공식 모범답안이 아니라 기술사 학습용 예시답안
- 1교시: 정의 → 핵심기술/특징 → 적용/고려사항 중심
- 2~4교시: 개요 → 구조/원리 → 세부사항 → 비교/대응 → Best Practice 중심
- 표준/제도 문제는 출제시점 기준을 우선하고 필요한 경우 최신 변경사항을 별도 표시
