# 컴시응 Study Mobile v1.5.2

## 객관식 학습 기능 개선
- 누적 풀이 횟수 표시
- 전체 누적 정답률 표시
- 분야별 정답률 통계
- 오답노트 자동 저장
- 마지막 풀이에서 틀린 문제를 오답노트에 유지
- 오답을 다시 맞히면 오답노트에서 자동 제거
- 틀린 문제만 랜덤으로 다시 풀기
- 오답노트에서 한 문제만 다시 풀기
- 오답노트에서 정답/해설/연계 기출 확인
- 객관식 학습 기록만 별도로 초기화 가능

## 기존 기능 유지
- 객관식 120문항
- 분야별 필터
- 10/20/30/50/전체 출제
- 1~4교시 실전 모의고사
- 서술형 연습모드
- 제135회 학습용 기본답안
- 다크/라이트 모드

객관식 통계는 브라우저 localStorage의 comsiQuizStatsV1에 저장됩니다.
