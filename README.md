# 컴시응 Study V1

Windows에서 시작하는 개인용 컴퓨터시스템응용기술사 학습 PWA입니다.

## 가장 쉬운 실행
1. 압축을 풉니다.
2. `index.html`을 더블클릭합니다.
3. Chrome 또는 Edge에서 열립니다.

기출 검색/분류 수정/답안 작성/통계/퀴즈는 로컬에서 동작합니다. 수정 내용은 브라우저 `localStorage`에 저장됩니다.

## 데이터
- 원본: 제96~135회 컴퓨터시스템응용기술사 PDF
- 자동 추출된 문제 수: 718개
- 주의: 일부 과거 회차는 스캔 페이지 때문에 텍스트 자동 추출이 누락될 수 있습니다.
- 기본 분류는 2023~2026 공식 출제기준의 8개 주요항목을 기준으로 키워드 자동분류한 초기값입니다.

## iPhone에서 앱처럼 쓰기
iPhone에서 사용하려면 이 폴더를 HTTPS 웹주소에 올리는 과정이 한 번 필요합니다. 다음 단계에서 무료 GitHub Pages 배포를 같이 진행하면 됩니다. 배포 후 Safari → 공유 → 홈 화면에 추가를 선택하면 됩니다.

## 파일 설명
- index.html : 앱 화면
- style.css : 디자인
- app.js : 앱 동작
- questions.js : 기출 DB
- quiz.js : V1 퀴즈 데이터
- manifest.json / sw.js : PWA 설치·오프라인 기능
